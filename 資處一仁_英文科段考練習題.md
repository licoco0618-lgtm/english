# 【參考答案與解析】

### 一、單字填空
1. **subject**（主題；學科）
2. **command**（命令；掌握）
3. **corner**（街角；角落）
4. **elevator**（電梯）
5. **package**（包裹）
6. **result**（結果）
7. **purpose**（目的）
8. **surprise**（驚訝）
9. **request**（請求；要求）
10. **relation**（關係）

### 二、文意字彙
1. **personal**（個人的、私人的；personal life 私生活）
2. **introduce**（介紹；introduce oneself 自我介紹）
3. **members**（成員；注意六位需用複數 members）
4. **respect**（尊重；show respect for 表達對...的尊敬）
5. **Therefore**（因此；字首請大寫）
6. **symbol**（象徵；a symbol of luck 幸運的象徵）
7. **likely**（可能的；be likely to + VR 有可能...）
8. **tradition**（傳統；family tradition 家族傳統，名詞）
9. **skills**（技能；computer skills 電腦技能）
10. **impressed**（使...留下深刻印象；過去式加 ed）

### 三、日常情境會話
1. **C**（Fine, thank you. And how are you? -> 很好，謝謝，你也好嗎？）
2. **E**（How are you? -> 你好嗎？）
3. **B**（I've caught a cold. -> 我感冒了。）
4. **A**（I appreciate it. -> 非常感謝。）
5. **D**（What's wrong with you? -> 怎麼啦？）

### 四、課文默寫填空
1. **bring**（bring fun and joy 帶來樂趣與喜悅）
2. **children**（birthday children 壽星孩子們）
3. **and**（連接詞，連接 getting presents 與 enjoying birthday celebrations）
4. **Romans**（古羅馬人，字首需大寫）
5. **around**（around the world 全世界）

### 五、翻譯填空
1. **costume** / **stage**（戲服 / 舞臺）
2. **In** / **addition** / **to**（片語：除了...之外）
3. **In** / **fact**（片語：事實上）
4. **move** / **on**（片語：繼續前進）
5. **look** / **around**（片語：四處參觀、環顧）
6. **blow** / **out**（片語：吹熄）
7. **keep** / **away**（片語：驅逐、使遠離；keep ... away）
8. **For** / **example**（片語：例如）
9. **according** / **to**（片語：按照、根據）
10. **look** / **forward** / **to**（片語：期待；to 後面接動名詞 seeing）
